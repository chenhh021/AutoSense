# 用户账号


## 用户登录


**接口地址**:`/api/v1/users/login`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`application/json`


**接口描述**:<p>校验账号和密码并签发不透明 Bearer 访问令牌。账号不存在、密码错误或账号已禁用时，统一返回 401，避免泄露具体失败原因。</p>



**请求示例**:


```javascript
{
  "userAccount": "zhangsan",
  "userPassword": "pass1234"
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|loginRequest|用户登录请求|body|true|LoginRequest|LoginRequest|
|&emsp;&emsp;userAccount|用户登录账号||true|string||
|&emsp;&emsp;userPassword|用户登录密码||true|string(password)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|登录成功|LoginResponse|
|400|账号或密码字段为空|ErrorResponse|
|401|账号或密码错误，或账号已禁用（错误码：UNAUTHORIZED）|ErrorResponse|
|500|服务内部错误|ErrorResponse|


**响应状态码-200**:


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|token|访问令牌，在需要认证的接口中通过 Authorization 请求头传递|string||
|tokenType|令牌类型，固定为 Bearer|string||
|user|当前登录用户的脱敏信息|UserView|UserView|
|&emsp;&emsp;id|用户唯一标识|integer(int64)||
|&emsp;&emsp;userAccount|用户登录账号|string||
|&emsp;&emsp;userName|用户昵称|string||
|&emsp;&emsp;userAvatar|用户头像地址|string||
|&emsp;&emsp;userProfile|用户简介|string||
|&emsp;&emsp;userRole|用户角色,可用值:user,admin|string||


**响应示例**:
```javascript
{
	"token": "Bx8J5mK2pQ7wV4yN9cR6tL1sH3dF0aZg",
	"tokenType": "Bearer",
	"user": {
		"id": 12,
		"userAccount": "zhangsan",
		"userName": "张三",
		"userAvatar": "https://example.com/avatar/12.png",
		"userProfile": "智能家居爱好者",
		"userRole": "user"
	}
}
```


**响应状态码-400**:


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务错误码|string||
|message|便于阅读的错误原因|string||
|sessionId|关联的诊断会话 ID；用户账号接口通常为空|integer(int64)|integer(int64)|

## 注册用户


**接口地址**:`/api/v1/users/register`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`application/json`


**接口描述**:<p>创建普通用户账号。账号须为 4<del>32 位字母、数字或下划线；密码须为 8</del>64 位且同时包含字母和数字；注册角色固定为 user。</p>



**请求示例**:


```javascript
{
  "userAccount": "zhangsan",
  "userPassword": "pass1234",
  "confirmPassword": "pass1234"
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
