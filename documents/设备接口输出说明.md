# 设备操作接口说明

本文档描述设备模拟器对外暴露的 4 个设备操作接口，并给出目前支持的**全部设备种类**的输出示例。

## 通用规则

- 所有接口均为 `POST`，请求和响应均为 `application/json`。
- 服务默认监听 `http://localhost:8080`（由 `.env` 中 `PORT` 决定）。
- 设备仅在 `running`（运行中）状态时可被发现；已停止、离线、已删除或 SN 不存在的设备统一返回 `404`。
- 每次 `set` / `action` 会按设备的 `failure_probability` 掷失败概率；触发失败时不改变任何状态，HTTP 状态仍为 `200`，以 `success: false` + `SIMULATED_FAILURE` 错误对象表示。`get` 不掷失败概率。
- 每个设备相关的响应体中都包含 `sn` 字段。

## 统一错误格式

| 场景 | HTTP 状态码 | 响应体 |
|---|---|---|
| SN 不存在 / 设备停止 / 离线 / 已删除 | 404 | `{"code":"NOT_FOUND","message":"device not found"}` |
| 请求体非法 / 属性校验失败 / 动作未声明 | 400 | `{"code":"INVALID_REQUEST","message":"<具体原因>"}` |

## 目前支持的设备

| 设备种类 | 型号 | 类型代码 | 默认固件版本 |
|---|---|---|---|
| 智能灯泡（单色温） | MJDP09YL | LITE | 20250101-1.0.1 |
| 智能灯泡（彩色） | MJDPL01YL | LITE | 20250203-1.2.1 |
| 空调 | KFR035GW | AIRC | 20231023-5.3.1 |
| 空气净化器 | BLJ48WD240200PV | PURI | 20250530-2.0.3 |

## 1. 查询单个设备属性

**POST** `/device/{sn}/get`（请求体为空或 `{}`）

响应为与 `get_list` 单项一致的包装结构：`sn` + `success` + `properties`，其中 `properties` 恰好包含该型号 GET 能力声明的全部属性。

### 1.1 智能灯泡 MJDP09YL（单色温）

```
POST /device/LITE000000001/get
```

```json
{
  "sn": "LITE000000001",
  "success": true,
  "properties": {
    "power": true,
    "brightness": 50,
    "color_temperature": 4600,
    "online": true,
    "signal_strength": 0,
    "firmware_version": "20250101-1.0.1"
  }
}
```

### 1.2 智能灯泡 MJDPL01YL（彩色）

```
POST /device/LITE000000002/get
```

```json
{
  "sn": "LITE000000002",
  "success": true,
  "properties": {
    "power": true,
    "brightness": 50,
    "color": { "red": 128, "green": 128, "blue": 128 },
    "online": true,
    "signal_strength": 0,
    "firmware_version": "20250203-1.2.1"
  }
}
```

### 1.3 空调 KFR035GW

```
POST /device/AIRC000000001/get
```

```json
{

  "success": true,
  "properties": {
    "power": true,

    "error_code": "",
```

```
POST /device/PURI000000001/get
```


## 2. 批量查询设备属性

**POST** `/device/get_list`

请求体：`sns` 为 SN 数组（非空，元素必须是非空字符串）。响应 `results` 与请求顺序一致，每项都带 `sn`；单项失败不影响整批，HTTP 状态恒为 `200`。

```
POST /device/get_list
Content-Type: application/json
```

```json
{
  "sns": ["LITE000000001", "LITE000000002", "AIRC000000001", "PURI000000001", "LITE999999999"]
}
```

## 3. 设置设备属性

**POST** `/device/{sn}/set`

请求体为扁平属性表，键必须属于该型号的 SET 能力；操作是原子的——任一属性校验失败或触发模拟失败时，所有属性都不生效。响应 `properties` 回显修改后的值。

### 3.1 智能灯泡 MJDP09YL

```
POST /device/LITE000000001/set
```

```json
{ "power": true, "brightness": 80, "color_temperature": 4000 }
```

```json
{
  "sn": "LITE000000001",
  "success": true,
  "properties": { "power": true, "brightness": 80, "color_temperature": 4000 }
}
```

### 3.2 智能灯泡 MJDPL01YL（含嵌套对象 color）

```
POST /device/LITE000000002/set
```

```json
{ "brightness": 60, "color": { "red": 255, "green": 128, "blue": 0 } }
```

```json
{
  "sn": "LITE000000002",
  "success": true,
  "properties": {
    "brightness": 60,
    "color": { "red": 255, "green": 128, "blue": 0 }
  }
}
```

> `color` 的三个子键 `red` / `green` / `blue` 均为必填，缺任何一个都会整体失败。

### 3.3 空调 KFR035GW

```
POST /device/AIRC000000001/set
```

```json
{ "power": true, "mode": "COOL", "target_temperature": 24, "fan_speed": "HIGH" }
```

```json
{
  "sn": "AIRC000000001",
  "success": true,
  "properties": {
    "power": true,
    "mode": "COOL",
    "target_temperature": 24,
    "fan_speed": "HIGH"
  }
}
```

可写属性：`power`、`mode`（AUTO/COOL/HEAT/DRY/FAN）、`target_temperature`（16–30）、`fan_speed`（AUTO/LOW/MEDIUM/HIGH）、`swing`（OFF/VERTICAL/HORIZONTAL/AUTO）、`eco_mode`、`sleep_mode`。

### 3.4 空气净化器 BLJ48WD240200PV

```
POST /device/PURI000000001/set
```

```json
{ "power": true, "mode": "MANUAL", "fan_speed": "MEDIUM", "child_lock": true, "display_brightness": 70 }
```

```json
{
  "sn": "PURI000000001",
  "success": true,
  "properties": {
    "power": true,
    "mode": "MANUAL",
    "fan_speed": "MEDIUM",
    "child_lock": true,
    "display_brightness": 70
  }
}
```

可写属性：`power`、`mode`（AUTO/SLEEP/MANUAL）、`fan_speed`（LOW/MEDIUM/HIGH）、`child_lock`、`display_brightness`（0–100）。

### 3.5 模拟失败响应（set）

触发 `failure_probability` 时状态不变，返回：

```json
{
  "sn": "LITE000000001",
  "success": false,
  "error": { "code": "SIMULATED_FAILURE", "message": "simulated device operation failure" }
}
```

## 4. 调用设备动作

**POST** `/device/{sn}/action`

请求体 `action` 必填，必须是该型号能力文件中声明的动作；`parameters` 可选（当前无动作消费参数，保留前向兼容）。无论成功或失败，响应前都会等待设备的 `action_delay_seconds`。

### 4.1 智能灯泡 MJDP09YL / MJDPL01YL

支持动作：`reboot`、`firmware_upgrade`。

```
POST /device/LITE000000001/action
```

```json
{ "action": "reboot", "parameters": {} }
```

```json
{
  "sn": "LITE000000001",
  "action": "reboot",
  "success": true
}
```

### 4.2 空调 KFR035GW

支持动作：`reboot`、`self_diagnosis`、`clear_error`、`reset_filter_life`、`firmware_upgrade`。

```
POST /device/AIRC000000001/action
```

```json
{ "action": "reset_filter_life", "parameters": {} }
```

```json
{
  "sn": "AIRC000000001",
  "action": "reset_filter_life",
  "success": true
}
```

> 成功后将 `filter_life` 重置为 100；`clear_error` 将 `error_code` 清空。

### 4.3 空气净化器 BLJ48WD240200PV

支持动作：`reboot`、`self_diagnosis`、`reset_filter_life`、`sensor_calibration`、`firmware_upgrade`、`factory_reset`。

```
POST /device/PURI000000001/action
```

```json
{ "action": "sensor_calibration", "parameters": {} }
```

```json
{
  "sn": "PURI000000001",
  "action": "sensor_calibration",
  "success": true
}
```

> `factory_reset` 成功后状态恢复为出厂初始值。

### 4.4 模拟失败响应（action）

```json
{
  "sn": "AIRC000000001",
  "action": "reboot",
  "success": false,
  "error": { "code": "SIMULATED_FAILURE", "message": "simulated device operation failure" }
}
```

### 4.5 动作副作用

| 动作 | 成功后的副作用 |
|---|---|
| `reboot` | 响应后设备进入 `offline`，随机 1 ~ `offline_max_seconds` 秒后恢复 `running` |
| `firmware_upgrade` | 同 `reboot` 的离线周期；恢复上线时 `firmware_version` 替换为随机新版本 |
| `self_diagnosis` | 无 |
| `clear_error` | `error_code` 置空 |
| `reset_filter_life` | `filter_life` 重置为 100 |
| `sensor_calibration` | 无 |
| `factory_reset` | 状态恢复为该型号出厂初始值 |

设备处于 `offline` 期间与停止的设备一样，对 get/set/action 均返回 `404`。

## 附：curl 调用示例

```bash
# 查询单个设备
curl -s -X POST http://localhost:8080/device/LITE000000001/get

# 批量查询
curl -s -X POST http://localhost:8080/device/get_list \
  -H "Content-Type: application/json" \
  -d '{"sns":["LITE000000001","AIRC000000001"]}'

# 设置属性
curl -s -X POST http://localhost:8080/device/AIRC000000001/set \
  -H "Content-Type: application/json" \
  -d '{"mode":"COOL","target_temperature":24}'

# 调用动作
curl -s -X POST http://localhost:8080/device/PURI000000001/action \
  -H "Content-Type: application/json" \
  -d '{"action":"reboot","parameters":{}}'
```
