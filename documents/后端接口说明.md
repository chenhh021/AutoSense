# 后端接口说明

本文档描述 deviceSimulator 后端对外提供的 HTTP 接口，包含接口描述、请求参数、响应参数及示例。

## 1. 接口概述

| 项目 | 说明                                     |
|------|----------------------------------------|
| 默认 Base URL | `http://localhost:8081`                |
| API 前缀 | `/api/v1`                              |
| 数据格式 | JSON（`Content-Type: application/json`） |
| 跨域支持 | 已开启 CORS，允许所有来源访问                      |
| 认证 | 当前版本无需认证                               |

## 2. 通用错误响应

当接口返回非 2xx 状态码时，响应体统一为以下结构：

```json
{
  "code": "ERROR_CODE",
  "message": "错误描述",
  "details": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | 错误码，用于前端判断错误类型 |
| `message` | string | 可读的错误描述 |
| `details` | object | 额外信息，当前版本多为空 |

常见错误码：

| HTTP 状态码 | code | 触发场景 |
|-------------|------|----------|
| 400 | `INVALID_REQUEST` | 请求体不是合法 JSON、必填字段缺失、参数校验失败、命令不支持或命令参数越界 |
| 404 | `NOT_FOUND` | 设备不存在、设备已停止运行、设备型号不存在 |
| 409 | `DUPLICATE_SN` | 自定义 SN 已被占用 |
| 500 | `INTERNAL_ERROR` | 服务器内部错误 |

## 3. 公共数据结构

### 3.1 Device（设备对象）

```json
{
  "id": 1,
  "device_type_id": 1,
  "device_model_id": 1,
  "device_type_code": "LITE",
  "device_model_code": "LA001",
  "sn": "LITE123456789",
  "name": "LA001-a3f9b2",
  "running_status": "running",
  "state": {
    "brightness": 50,
    "color_temperature": 4600
  },
  "created_at": "2026-08-25T10:00:00Z",
  "updated_at": "2026-08-25T10:00:00Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备唯一 ID |
| `device_type_id` | integer | 设备类型内部 ID |
| `device_model_id` | integer | 设备型号内部 ID |
| `device_type_code` | string | 设备类型代码，例如 `LITE` |
| `device_model_code` | string | 设备型号代码，例如 `LA001`、`LB001` |
| `sn` | string | 13 位序列号 |
| `name` | string | 设备名称 |
| `running_status` | string | 运行状态：`running` / `stopped` |
| `state` | object | 设备当前状态，结构与型号相关 |
| `created_at` | string | 创建时间（RFC3339） |
| `updated_at` | string | 更新时间（RFC3339） |

### 3.2 当前支持的设备目录

`GET /api/v1/device-catalog` 返回的设备类型与型号如下：

| 类型代码 | 类型名称 | 型号代码 | 型号名称 | 支持功能 |
|----------|----------|----------|----------|----------|
| `LITE` | smart light | `LA001` | Monochrome bulb | `brightness`、`color_temperature` |
| `LITE` | smart light | `LB001` | Color bulb | `brightness`、`color` |

### 3.3 各型号初始状态

- `LA001`：`{ "brightness": 50, "color_temperature": 4600 }`
- `LB001`：`{ "brightness": 50, "color": { "r": 128, "g": 128, "b": 128 } }`

## 4. 接口列表

### 4.1 健康检查

- **接口描述**：检查服务健康状态。
- **请求方式**：`GET /healthz`
- **入参**：无

**出参**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | 固定返回 `ok` |

**示例响应**：

```json
{
  "status": "ok"
}
```

---

### 4.2 获取设备类型目录

- **接口描述**：获取所有设备类型及其型号、支持的功能列表。创建设备页面依赖此接口填充下拉选项。
- **请求方式**：`GET /api/v1/device-catalog`
- **入参**：无

**出参**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `types` | array | 设备类型数组 |
| `types[].id` | integer | 类型 ID |
| `types[].code` | string | 类型代码 |
| `types[].name` | string | 类型名称 |
| `types[].models` | array | 该类型下的型号数组 |
| `types[].models[].code` | string | 型号代码 |
| `types[].models[].name` | string | 型号名称 |
| `types[].models[].functions` | array | 该型号支持的功能标识 |

**示例响应**：

```json
{
  "types": [
    {
      "id": 1,
      "code": "LITE",
      "name": "smart light",
      "models": [
        {
          "id": 1,
          "device_type_id": 1,
          "code": "LA001",
          "name": "Monochrome bulb",
          "functions": ["brightness", "color_temperature"]
        },
        {
          "id": 2,
          "device_type_id": 1,
          "code": "LB001",
          "name": "Color bulb",
          "functions": ["brightness", "color"]
        }
      ]
    }
  ]
}
```

---

### 4.3 创建设备

- **接口描述**：根据设备类型和型号创建一个或多个设备。`quantity` 为 1 时返回单个设备对象；大于 1 时返回设备数组包装。
- **请求方式**：`POST /api/v1/devices`

**入参（请求体）**：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `device_type_code` | string | 是 | 设备类型代码，当前仅支持 `LITE` |
| `device_model_code` | string | 是 | 设备型号代码，如 `LA001`、`LB001` |
| `quantity` | integer | 否 | 创建数量，默认 `1`，取值范围 `1~100` |
| `name` | string | 否 | 设备名称；为空时按 `{model_code}-{6 位随机字符}` 生成 |
| `sn` | string | 否 | 自定义序列号，须为 13 位；为空时按 `{type_code}{9 位随机数字}` 生成 |

**示例请求**：

```json
{
  "device_type_code": "LITE",
  "device_model_code": "LA001",
  "quantity": 1,
  "name": "客厅灯"
}
```

**出参（quantity=1，HTTP 201）**：Device 对象

**出参（quantity>1，HTTP 201）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `devices` | array | 创建的设备对象数组 |

**示例响应（quantity=1）**：

```json
{
  "id": 1,
  "device_type_id": 1,
  "device_model_id": 1,
  "device_type_code": "LITE",
  "device_model_code": "LA001",
  "sn": "LITE123456789",
  "name": "客厅灯",
  "running_status": "running",
  "state": {
    "brightness": 50,
    "color_temperature": 4600
  },
  "created_at": "2026-08-25T10:00:00Z",
  "updated_at": "2026-08-25T10:00:00Z"
}
```

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `quantity` 超出 1~100 范围；型号不属于该类型；`sn` 长度不等于 13 |
| 409 | `sn` 已被现有设备占用 |

---

### 4.4 列出运行中的设备

- **接口描述**：获取当前运行状态为 `running` 的设备列表。已停止或已删除的设备不会返回。
- **请求方式**：`GET /api/v1/devices`
- **入参**：无

**出参**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `devices` | array | 运行中设备对象数组 |

**示例响应**：

```json
{
  "devices": [
    {
      "id": 1,
      "device_type_id": 1,
      "device_model_id": 1,
      "device_type_code": "LITE",
      "device_model_code": "LA001",
      "sn": "LITE123456789",
      "name": "客厅灯",
      "running_status": "running",
      "state": {
        "brightness": 50,
        "color_temperature": 4600
      },
      "created_at": "2026-08-25T10:00:00Z",
      "updated_at": "2026-08-25T10:00:00Z"
    }
  ]
}
```

---

### 4.5 获取单个设备

- **接口描述**：根据 ID 获取设备完整信息，包括当前状态。
- **请求方式**：`GET /api/v1/devices/{id}`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**出参**：Device 对象

**示例响应**：同 4.3 中 quantity=1 示例

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 不是合法整数 |
| 404 | 设备不存在或已停止运行 |

---

### 4.6 更新设备名称

- **接口描述**：修改设备名称。当前版本仅支持修改 `name` 字段。
- **请求方式**：`PATCH /api/v1/devices/{id}`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**入参（请求体）**：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `name` | string | 是 | 新名称，长度 `1~64` 字符 |

**示例请求**：

```json
{
  "name": "卧室灯"
}
```

**出参**：更新后的 Device 对象

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `name` 为空或超过 64 字符；`id` 非法 |
| 404 | 设备不存在 |

---

### 4.7 删除设备

- **接口描述**：删除指定设备。删除后该 SN 可立即被重新使用。
- **请求方式**：`DELETE /api/v1/devices/{id}`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**出参**：无（HTTP 204）

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 不是合法整数 |
| 404 | 设备不存在 |

---

### 4.8 启动设备

- **接口描述**：将设备运行状态设置为 `running`。已运行的设备再次启动会报错。
- **请求方式**：`POST /api/v1/devices/{id}/start`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**入参（请求体）**：无

**出参**：更新后的 Device 对象

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 非法；设备已是 running 状态 |
| 404 | 设备不存在 |

---

### 4.9 停止设备

- **接口描述**：将设备运行状态设置为 `stopped`。停止后设备不再出现在列表中，也无法接收控制命令。已停止的设备再次停止会报错。
- **请求方式**：`POST /api/v1/devices/{id}/stop`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**入参（请求体）**：无

**出参**：更新后的 Device 对象

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 非法；设备已是 stopped 状态 |
| 404 | 设备不存在 |

---

### 4.10 执行设备命令

- **接口描述**：向运行中的设备下发控制命令。命令必须被该设备型号支持，参数需在合法范围内。
- **请求方式**：`POST /api/v1/devices/{id}/commands`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**入参（请求体）**：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| `command` | string | 是 | 命令名称 |
| `parameters` | object | 是 | 命令参数对象 |

**支持的命令**：

| 型号 | 命令 | 参数 | 说明 |
|------|------|------|------|
| `LA001` | `set_brightness` | `{ "brightness": 1~100 }` | 设置亮度 |
| `LA001` | `set_color_temperature` | `{ "color_temperature": 2700~6500 }` | 设置色温 |
| `LB001` | `set_brightness` | `{ "brightness": 1~100 }` | 设置亮度 |
| `LB001` | `set_color` | `{ "color": { "r": 0~255, "g": 0~255, "b": 0~255 } }` | 设置颜色 |

**示例请求**：

```json
{
  "command": "set_brightness",
  "parameters": {
    "brightness": 80
  }
}
```

**出参**：更新后的 Device 对象，`state` 已反映命令执行结果

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 非法；命令不被支持；参数缺失或越界 |
| 404 | 设备不存在或已停止运行 |

---

### 4.11 获取设备数据

- **接口描述**：仅返回设备的当前 `state` 数据，等价于 `GET /api/v1/devices/{id}` 中的 `state` 字段。
- **请求方式**：`GET /api/v1/devices/{id}/data`

**入参（路径参数）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 设备 ID |

**出参**：设备状态对象

**示例响应（LA001）**：

```json
{
  "brightness": 80,
  "color_temperature": 4600
}
```

**示例响应（LB001）**：

```json
{
  "brightness": 50,
  "color": {
    "r": 128,
    "g": 128,
    "b": 128
  }
}
```

**常见错误**：

| HTTP 状态码 | 触发场景 |
|-------------|----------|
| 400 | `id` 不是合法整数 |
| 404 | 设备不存在或已停止运行 |

|------|------|------|
| GET | `/healthz` | 健康检查 |

| POST | `/api/v1/devices` | 创建设备 |
| GET | `/api/v1/devices` | 列出运行中设备 |
| GET | `/api/v1/devices/{id}` | 获取单个设备 |
| PATCH | `/api/v1/devices/{id}` | 更新设备名称 |
| DELETE | `/api/v1/devices/{id}` | 删除设备 |
| POST | `/api/v1/devices/{id}/start` | 启动设备 |
| POST | `/api/v1/devices/{id}/stop` | 停止设备 |
| POST | `/api/v1/devices/{id}/commands` | 执行设备命令 |
| GET | `/api/v1/devices/{id}/data` | 获取设备状态数据 |
